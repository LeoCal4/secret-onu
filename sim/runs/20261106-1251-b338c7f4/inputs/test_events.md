# Test Events
Cost to handle an event (resources): 6 / 8 / 10 / 12 for 3 / 4 / 5 / 6 players.
Effects below apply ONLY if the event is NOT handled. Tracks: Environment (ECO), Economy (ECN), Social (SOC), range 0-20.

1. Heatwave Across Continents: -3 ECO, -1 SOC
2. Global Stock Market Crash: -4 ECN
3. Oil Tanker Spill: -3 ECO, -1 ECN
4. Refugee Crisis: -3 SOC, -1 ECN
5. Pandemic Outbreak: -2 SOC, -2 ECN
6. Mass Protests Against Inequality: -3 SOC
7. Crop Failures: -2 ECO, -2 SOC
8. Cyberattack on Financial Systems: -3 ECN, -1 SOC
9. Rainforest Wildfires: -4 ECO
10. Trade War Escalation: -3 ECN. Next turn, the President cannot choose a Vote card affecting Quadrant B.
11. Disinformation Wave: -2 SOC. Next turn, the President must reveal the Vote card's back to the table before allocation (no lying possible).
12. Energy Grid Blackouts: -2 ECN, -2 SOC
13. Glacier Collapse: -3 ECO. Quadrant A moves 1 step toward 1.
14. Sovereign Debt Crisis: -3 ECN. Quadrant B moves 1 step toward 1.
15. Diplomatic Incident: -1 ECO, -1 ECN, -1 SOC. Next turn, the Vote requires +2 resources to pass.
16. Water Scarcity: -2 ECO, -1 ECN, -1 SOC
17. Industrial Accident: -2 ECO, -2 ECN
18. Wave of Authoritarianism: -3 SOC. Quadrant C moves 1 step toward 1.
19. Resource Scramble: -2 ECO, -1 ECN. Quadrant D moves 1 step toward 1.
20. Unexpected Technological Breakthrough (positive): +2 ECN, +2 ECO if handled; if not handled, nothing happens (missed opportunity), but the unresolved-events counter still increases.
